# 탐색 알고리즘

구현: `engine/app/search/`

## 0. 회랑(corridor) 추출

출발 O·도착 D 직선거리를 `d`라 하면, 노드 n은
`dist(O,n) + dist(n,D) ≤ max(1.4·d, d + 1500m)` 이면 회랑 안이다(타원, 초점 O·D).
대중교통(`board/ride/alight/vertical`) 엣지는 `max(2.0·d, d + 4000m)` 넓은 회랑을 쓴다.
PostGIS에서는 bbox 인덱스 필터 후 `ST_Distance` 합으로 구한다.

## 1. 전처리

1. 출발·도착 좌표를 가장 가까운 `walk` 노드에 스냅한다(KD-tree, 최대 300 m).
2. 비용 모델로 모든 엣지 비용 `c(e)`를 계산한다. 차단 엣지는 제거한다.
3. D에서 역방향 Dijkstra를 돌려 `h(v)` = v에서 D까지 최소 비용을 구한다.
   `h(v)=∞`인 노드는 D에 도달할 수 없으므로 개미가 절대 진입하지 않는다.
4. 시드 경로: 순방향 Dijkstra 최단 경로 1개 + 페널티 KSP(사용한 엣지 비용 ×1.6 후 재탐색) 3개.

## 2. ACO (MMAS + ACS 의사난수 규칙)

- 파라미터(기본): 개미 `m=24`, 반복 `n_iter=60`, `α=1.0`, `β=2.5`, `ρ=0.12`, `q0=0.35`,
  시간 예산 `time_budget_s=2.5`.
- 휴리스틱: `η(e) = 1 / (c(e) + λ·h(v))`, `λ=0.6`. cost-to-go를 섞어 개미가 목적지를 향하게 하되,
  페로몬과 확률 선택이 우회를 허용한다.
- 선택: 노드 u에서 아직 방문하지 않은 v로 가는 엣지 중
  `p(e) ∝ τ(e)^α · η(e)^β`. 확률 `q0`로 argmax(활용), 아니면 룰렛(탐험).
- 개미는 최대 `3 × len(seed_path)` 스텝 안에 D에 도달하지 못하면 버려진다.
- 페로몬: `τ0 = 1 / (ρ · C_seed)`, `τ_max = τ0`, `τ_min = τ_max / (2 · |E_corridor|^0.5)`.
  매 반복 `τ ← (1-ρ)τ`, 반복 최고·전역 최고 경로에 `Δτ = 1/C` 적립, `[τ_min, τ_max]`로 클램프.
- 아카이브: 모든 개미 경로를 엣지 튜플 기준으로 중복 제거해 `(cost, path)`로 보관한다.
- 종료: 반복 수, 시간 예산, 또는 20회 연속 전역 최고 갱신 없음.

## 3. GA (아카이브 다듬기)

- 초기 개체: ACO 아카이브 상위 30 + 시드.
- 표현: 노드 id 리스트(단순 경로).
- 교차: 두 부모의 공통 중간 노드 하나를 무작위로 골라 앞·뒤를 잇는다. 반복 노드가 생기면
  첫 등장~마지막 등장 사이를 잘라 루프를 없앤다.
- 변이: 경로의 부분 구간 `[i, j]`(길이 ≤ 30 %)를 고르고, 구간 밖 노드를 금지한 상태에서
  `c(e) × U(0.6, 1.8)`, 현재 경로 엣지는 ×3 페널티로 Dijkstra 재탐색해 교체한다.
- 적합도 = 비용(낮을수록 좋음). 토너먼트 선택 k=3, 엘리트 2, 세대 25, 개체 30.
- 결과 개체는 아카이브에 합류한다.

## 4. 다양성 Top 3

아카이브를 비용 오름차순으로 훑으며 다음을 만족하는 경로를 고른다.

- 이미 고른 경로들과의 **길이 가중 엣지 Jaccard 중복률 ≤ 0.6**
- 비용 ≤ 최고 비용 × 1.6

3개를 못 채우면 중복률 기준을 0.8, 그다음 1.0으로 완화한다.

## 5. 경로 특성과 배지

| 배지 | 조건 |
|---|---|
| `fastest` | 3개 중 순수 시간 최소 |
| `shortest_walk` | 도보 거리 최소 |
| `gentlest_slope` | 최대 경사 최소 (경사 정보 있을 때) |
| `most_shade` | 그늘 비율 최대 (낮 + 건물 정보 있을 때, 차이 ≥ 0.05) |
| `fewest_transfers` | 환승 최소 (차이가 있을 때) |
| `stair_free` | 계단 구간 0 |
| `elevator_confirmed` | 모든 수직 이동이 확인된 엘리베이터 |

주의사항(`cautions`): 경사 8 % 초과 구간, 계단 n곳, 미확인 엘리베이터, 폭염 시 그늘 없는 도보 500 m 초과,
저상버스 비율 낮음 등.
